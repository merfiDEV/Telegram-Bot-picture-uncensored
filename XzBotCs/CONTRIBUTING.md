# Contributing to XzBotCs

Спасибо за интерес к проекту! Ниже — краткое руководство по внесению вклада.

## Как начать
1. Форкните репозиторий и создайте ветку с описательным именем: `feature/имя` или `fix/описание`.
2. Делайте маленькие, атомарные коммиты с осмысленными сообщениями.

## Ветвление и PR
- Открывайте Pull Request в основную ветку репозитория. В PR опишите цель, изменения и как их тестировать.
- Запросы на изменения могут включать предложения по улучшению стиля кода или архитектуры.

## Стиль кода
- Соблюдайте общие соглашения C# (naming, PascalCase для публичных членов).
- Форматируйте код с помощью `dotnet format` при необходимости.

## Тестирование
- Добавляйте тесты для новой функциональности. Если вы не уверены, опишите шаги ручной проверки в PR.

## Безопасность и приватность
- Не включайте секреты, API-ключи или пароли в коммиты. Используйте переменные окружения.

## Контакт
- Если нужна помощь — создайте issue или отметьте владельцев репозитория в PR.
