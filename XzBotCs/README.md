# XzBotCs

Простой Telegram-бот на C# для генерации и обработки картинок.

## Коротко
- Язык: C# (.NET 10)
- Назначение: серверная логика Telegram-бота с механизмами поиска и водяных знаков

## Быстрый старт

Требования:
- .NET 10 SDK

Сборка и запуск (от корня репозитория):

```powershell
dotnet build
dotnet run
```

Файл состояния бота: `bot_state.json` — проверьте и при необходимости обновите.

## Структура проекта
- `Models/` — модели данных (например, `BotState.cs`)
- `Services/` — сервисы приложения (BingSearchService, BotStatsService, WatermarkService)

## Конфигурация
- В корне проекта присутствует `bot_state.json` для сохранения состояния.
