# 🤝 Руководство для контрибьюторов (Contributor Guide)

Приветствуем! Мы очень рады, что вы заинтересовались проектом **XZ Inline Image Search Bot**. Это руководство создано, чтобы помочь вам легко и быстро начать вносить свой вклад в развитие бота.

Любая помощь приветствуется: от исправления опечаток в документации до рефакторинга архитектуры и добавления новых фич!

---

## 💡 Как вы можете помочь?

1. **Сообщить об ошибке (Bug Report):** 
   Нашли баг или бот упал с ошибкой? Создайте Issue в репозитории с подробным описанием:
   - Шаги воспроизведения.
   - Ожидаемый и фактический результат.
   - Логи ошибок (если есть).

2. **Предложить идею (Feature Request):** 
   Есть классная идея, как сделать бота еще лучше? Напишите нам об этом в Issue, описав, какую проблему решает ваша идея.

3. **Написать код или исправить баг (Pull Request):** 
   Готовы написать код? Отлично! Мы всегда рады вашим PR.

---

## 🛠 Процесс разработки (Шаги для PR)

### 1. Подготовка
1. Сделайте форк (Fork) этого репозитория на свой аккаунт GitHub.
2. Склонируйте форк на свой локальный компьютер:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/Telegram-Bot-picture-uncensored.git
   ```
3. Убедитесь, что у вас установлен **.NET SDK 10.x** (или актуальная версия, указанная в README).

### 2. Создание ветки (Branch)
Никогда не коммитьте напрямую в ветку `main`. Создавайте новую ветку для каждой задачи:
```bash
git checkout -b feature/добавление-новой-фичи
# или для багфиксов
git checkout -b fix/описание-исправления
```

### 3. Написание кода
- Старайтесь следовать общим стандартам написания чистого кода на C# (Clean Code, SOLID).
- Если вы добавляете сложную логику — оставляйте комментарии.
- Не забывайте обновлять документацию, если ваши изменения затрагивают конфигурацию или использование бота.

### 4. Коммит и Push
Напишите понятное сообщение для коммита, желательно по стандарту *Conventional Commits*:
```bash
git commit -m "feat: добавлена поддержка новых поисковых фильтров"
# или
git commit -m "fix: исправлена ошибка при парсинге GIF анимаций"
```
Отправьте изменения в ваш форк:
```bash
git push origin название-вашей-ветки
```

### 5. Создание Pull Request
Перейдите в оригинальный репозиторий и нажмите "Compare & pull request". 
- Пожалуйста, подробно опишите, что именно вы изменили.
- Укажите номер Issue, если PR закрывает какую-то конкретную проблему (например: `Fixes #12`).

## 🏗 Кратко об архитектуре

Основной код проекта находится в папке `XzBotCs`. 
Ключевые компоненты:
- **`Program.cs`** — Точка входа в приложение, настройка DI (Dependency Injection), инициализация бота и логгера.
- **`Services/`** — Папка с бизнес-логикой:
  - `BingSearchService.cs` — отвечает за парсинг картинок из поисковика.
  - `WatermarkService.cs` — отвечает за добавление водяных знаков и проксирование изображений.
- **`Models/`** — Классы данных, конфигурации и модели десериализации JSON.
