### 11. `Services/WatermarkService.cs`

### 12. `Services/BotStatsService.cs`
- Добавить `: IStatsService`
- Удалить дублированный `Escape()` (строки 324-333), заменить вызовы на `TelegramEscaper.EscapeMarkdownV2()`

### 13. `Models/BotState.cs`
- Добавить `private static readonly object _saveLock = new object();` для синхронизации `Save()`
- Обернуть `Save()` в `lock(_saveLock)` — исправление race condition
- Добавить логирование в `catch` блоки `Load()` и `Save()` (Console.WriteLine)
- В `Load()` после десериализации обрезать `ResponseTimesMs` до 1000 записей

### 14. `Program.cs` — упростить до точки входа с DI
- Удалить всю логику, оставить только:
  - Регистрация DI-контейнера (`ServiceCollection`)
  - Создание `ServiceProvider`
  - Получение `AppConfig`, создание `TelegramBotClient`
  - Запуск `UpdateHandler` и `ProxyServer`
  - Ожидание Ctrl+C

### 15. `XzBotCs.csproj`
- Добавить `<PackageReference Include="Microsoft.Extensions.DependencyInjection" Version="10.0.7" />`
- Удалить неиспользуемые пакеты:
  - `Microsoft.Extensions.Configuration` (10.0.7)
  - `Microsoft.Extensions.Configuration.EnvironmentVariables` (10.0.7)
  - `Microsoft.Extensions.Configuration.Json` (10.0.7)
