# XZ Inline Image Bot

Telegram inline-бот для поиска картинок и GIF через Bing Images. Эта версия перенесена на C# / .NET и содержит фичи из старой Python-версии.

## Возможности

| Возможность | Что дает |
|---|---|
| Inline-поиск | Поиск картинок прямо в любом чате через `@bot query` |
| GIF-режим | Флаг `--gif` включает поиск анимаций |
| Пустой запрос | Бот показывает аккуратную подсказку вместо пустой выдачи |
| Проверка ссылок | Перед отправкой бот проверяет, что URL действительно ведет на изображение |
| Удаление дублей | Одинаковые картинки отсекаются по хешу очищенного URL |
| Пагинация | Telegram может подгружать следующие результаты |
| Кнопка источника | Под результатом есть переход на сайт-источник или оригинал |
| Профиль разработчика | В inline-выдаче есть верхняя кнопка профиля разработчика |
| Watermark proxy | Можно включать/выключать ватермарку из админки |
| Админ-статистика | `/stats` показывает состояние бота, Bing и счетчики |
| Метрики | Среднее/минимальное/максимальное время ответа Bing |
| Дашборд запросов | Последние запросы пользователей доступны админу |
| Логи | `/logs` отправляет архив логов администратору |

## Быстрый старт

### 1. Установить .NET

Нужен .NET SDK 10.x.

### 2. Создать `.env`

Файл `.env` должен лежать в корне репозитория:

```env
BOT_TOKEN=telegram_bot_token_from_botfather
ADMIN_ID=your_telegram_id
```

Опционально для watermark-прокси:

```env
PROXY_BASE_URL=https://your-domain.com/img?u=
PROXY_PORT=8080
```

`PROXY_BASE_URL` должен быть публично доступен серверам Telegram. Если он не задан, бот будет отдавать прямые ссылки на изображения без проксирования.

### 3. Запустить

```bash
dotnet run --project XzBotCs/XzBotCs.csproj
```

## Команды

| Команда | Доступ | Назначение |
|---|---:|---|
| `/start` | всем | Инструкция и кнопка запуска inline-поиска |
| `/start developer` | всем | Карточка со ссылкой на профиль разработчика |
| `/stats` | admin | Статистика, здоровье Bing, метрики и дашборд |
| `/logs` | admin | Скачать архив логов |

## Inline-использование

Открой любой чат и начни вводить:

```text
@имя_бота запрос
```

Примеры:

```text
@имя_бота cyberpunk city
@имя_бота anime wallpaper
@имя_бота кот мем --gif
```

Если после имени бота ничего не ввести, бот покажет подсказку.

## Как работает поиск

1. Пользователь вводит inline-запрос в Telegram.
2. Бот проверяет флаг `--gif`.
3. Сервис делает запрос к Bing Images.
4. Из HTML-ответа достаются `murl`, `turl` и `purl`.
5. Каждая ссылка проверяется через `HEAD`, а при необходимости через `GET`.
6. Дубли отсекаются по хешу очищенного URL.
7. Telegram получает список `InlineQueryResultPhoto` или `InlineQueryResultGif`.

## Админ-мониторинг

`/stats` доступна только `ADMIN_ID` и показывает:

- аптайм;
- время запуска;
- доступность Bing;
- количество запросов;
- количество ошибок;
- success rate;
- среднее, минимальное и максимальное время ответа Bing;
- последние запросы пользователей.

`/logs` доступна только в личных сообщениях с ботом и отправляет `logs.zip`.
